| 屬性 | 內容 |
|---|---|
| 📅 日期 | 2026-11-25 |
| ✍️ 提出 | 林宇鑫（衣物生成） |
| 🎯 目的 | 試穿頁的衣服現在是單色、一整片很圓滑，看不出縫線。加上**縫線貼圖**（車縫線、接縫、羅紋、門襟、口袋）和**扣子**，看起來像真的衣服 |

# 一、我這邊輸出的檔案

每件衣服的資料夾（`garment/meshes/neutral/<代號>_<名稱>/`）多出：

| 檔案 | 內容 |
|---|---|
| `<資料夾>_uv.json` | `vt`：UV 座標列表 `[[u, v], …]`；`ft`：**每個面三個角**的 UV 編號 `[[a, b, c], …]`，第 k 個對應 OBJ 第 k 個 `f`，角的順序也一樣；`color`、`normal`：貼圖檔名 |
| `<資料夾>_color.png` | 顏色貼圖（2048²，已經是真的顏色，材質顏色設白色） |
| `<資料夾>_normal.png` | 法線貼圖（切線空間、OpenGL 慣例 +y 往上，Three.js 預設就是） |
| `parts.obj`（有才有） | 立體零件，每個 `o` 一顆扣子或一條帽繩，公尺、和衣服同座標（T-pose 時的位置） |
| `parts_attach.json`（有才有） | 每個零件掛在哪裡：扣子＝`face`（OBJ 第幾個面，0 起算）＋`bary`（重心座標）＋`offset_cm`（沿面法向往外）；帽繩＝`anchor_vertex`（上端固定在哪個頂點） |

`_pins.json` 的 `has_uv` 會變成 `true`。

**為什麼 UV 不直接寫進 OBJ**：同一個頂點在縫線兩側的 UV 不同（兩片版片），UV 只能「每個面的角」各一個；
試穿頁現在的 `parseObj` 一個頂點只有一個位置，要拆開才放得下 UV（見三、①）。分開放就不用動 OBJ 和 engine 讀衣服的部分。

# 二、紀泓宇：engine 要做的

試穿頁現在從 `http://<engine>:<埠>/mesh.obj` 拿衣服的面，這個 OBJ 是 engine 用頂點、面重新寫的，沒有 UV。

| # | 要做的 | 說明 |
|---|---|---|
| 1 | 衣服埠多提供 `/uv.json`、`/color.png`、`/normal.png` | 直接回傳衣服資料夾裡的 `<資料夾>_uv.json`、`_color.png`、`_normal.png`；沒有就回 404（試穿頁就用現在的單色） |
| 2 | 有零件的多提供 `/parts.obj`、`/parts_attach.json` | 同上，照抄檔案 |
| 3 | **確認 `/mesh.obj` 的面順序和衣服 OBJ 一樣** | `_uv.json` 的 `ft` 是照衣服 OBJ 的面順序排的。如果 engine 載入時有重排、刪掉、翻轉面，要告訴我，我照 engine 的順序輸出 |
| 4 | （之後再說）帽繩 | 帽繩只固定上端，要當成繩子模擬才會晃；先不做也可以，試穿頁可以先不畫帽繩 |

# 三、趙丞章：試穿頁要做的

參考實作（可以直接看、直接抄）：`tools/texture/tryon_texture_reference.html`
從 newfashion_VT 根目錄 `python -m http.server 8766`，開
`http://localhost:8766/tools/texture/tryon_texture_reference.html?g=z02M_blue_cropped_shirt`，按「模擬串流」看每幀更新的效果。

| # | 要做的 | 參考實作裡的位置 |
|---|---|---|
| ① | 衣服載入 `/uv.json`，**照 (頂點, UV) 拆開頂點**，記住每個新頂點來自串流的哪個頂點（`src`） | `splitByUV()` |
| ② | 每幀收到串流的頂點位置後：先在**沒拆開的網格**上算法向（縫線處才不會出現假折痕），再照 `src` 把位置、法向抄到拆開的幾何 | `applyFrame()` |
| ③ | 材質：`MeshStandardMaterial({ map: color, normalMap: normal, normalScale: 1.6, roughness: 0.85, side: DoubleSide })`，顏色用白色 | |
| ④ | 扣子：每顆用 `parts_attach.json` 的 `face`、`bary`，每幀算目前三角形上的位置和法向，把扣子擺上去 | `facePose()`、`placeButtons()` |
| ⑤ | 沒有 `/uv.json` 的衣服照現在的方式畫 | |

成本：z02M 串流 3,748 頂點、拆開後 4,130；每幀多一次複製（幾千個點），扣子 6 顆，對幀率影響很小。
