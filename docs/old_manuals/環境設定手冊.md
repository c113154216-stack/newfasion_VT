# 3D 虛擬試穿後端 — 環境設定手冊

> 適用對象：趙丞章（後端）／協助對接的組員參考
> 專案路徑：`3Dclothes_project/`

---

## 一、系統與軟體需求

| 項目 | 版本 / 說明 |
|---|---|
| 作業系統 | Windows 10/11 |
| Python | 3.10～3.12（需能安裝 `faiss-cpu`） |
| pip | 隨 Python 安裝 |
| XAMPP | 只需要 MySQL，Apache 可不啟動 |
| Git | 可選，用於版本控制 |

---

## 二、XAMPP／MySQL 設定

1. 開啟 XAMPP 控制面板，啟動 **MySQL**（不需要啟動 Apache）
2. 用 phpMyAdmin 或 MySQL CLI 建立資料庫：

| 設定 | 值 |
|---|---|
| 資料庫名稱 | `3d_tryon`（**不要**沿用舊的 `uniqlo_tw`） |
| 字元集 | `utf8mb4` |
| 排序規則 | `utf8mb4_unicode_ci` |

3. 預設連線資訊（XAMPP 常見值）：

| 項目 | 值 |
|---|---|
| Host | `127.0.0.1` |
| Port | `3306` |
| User | `root` |
| Password | 通常為空（若有設密碼，需同步改 `.env`） |

---

## 三、Python 虛擬環境與套件

在專案根目錄執行：

```powershell
cd "c:\Users\User\EEproject\3Dclothes_project"
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### `requirements.txt` 套件說明

| 套件 | 用途 |
|---|---|
| flask | Web 後端框架 |
| flask-cors | 允許前端跨網域呼叫 API |
| sqlalchemy | ORM，操作 MySQL |
| pymysql | MySQL 驅動 |
| python-dotenv | 讀取 `.env` |
| faiss-cpu | 向量搜尋（FAISS） |
| numpy | 向量運算 |
| pillow | 圖片處理（測試與上傳） |
| pytest | 自動測試 |

## 四、環境變數（`.env`）

複製範本：
```powershell
copy .env.example .env
```

### 必設／建議設定的變數

| 變數 | 範例值 | 說明 |
|---|---|---|
| `DATABASE_URL` | `mysql+pymysql://root:@127.0.0.1:3306/3d_tryon` | MySQL 連線字串；有密碼時改成 `root:你的密碼@...` |
| `FAISS_INDEX_PATH` | `data/faiss_index/product.index` | FAISS 索引檔路徑 |
| `UPLOAD_FOLDER` | `data/uploads` | 商品圖上傳目錄 |
| `OUTPUT_FOLDER` | `data/outputs` | 試穿 GLB 輸出目錄 |
| `FLASK_ENV` | `development` | 開發模式（會開 SQL debug log） |
| `FAISS_VECTOR_DIM` | `512` | FashionCLIP 向量維度（預設 512） |
| `CORS_ORIGINS` | `http://localhost:5173` | 允許的前端來源；多個用逗號分隔 |

> ⚠️ `.env` 不要 commit（已列在 `.gitignore`）。

---

## 五、資料庫初始化

MySQL 與 `.env` 都設好後：

```powershell
python -m database.init_db
```

成功會建立三張表：`products`、`body_profiles`、`tryon_sessions`

開發模式下也可用 API 觸發：
```
POST http://127.0.0.1:5000/api/admin/init-db
```

## 六、目錄結構

程式啟動時會自動建立大部分目錄，但建議先確認以下結構存在：

```
3Dclothes_project/
├── .env                    # 本機設定（自行建立，不進 Git）
├── data/
│   ├── faiss_index/        # FAISS 索引（執行後產生 product.index）
│   ├── uploads/products/   # 商品圖
│   ├── outputs/            # 試穿 GLB
│   └── samples/            # stub 用的 sample_body.glb / sample_garment.glb
```

**不進 Git 的內容**（已在 `.gitignore`）：
- `.env`
- `data/uploads/`
- `data/outputs/`
- `data/faiss_index/*.index`

## 八、啟動與驗證步驟（完整流程）

```powershell
# 1. 進入專案、啟用 venv
cd "c:\Users\User\EEproject\3Dclothes_project"
.venv\Scripts\Activate.ps1

# 2. 確認 .env 已建立（第一次才需要）

python -m database.init_db

# 4. 啟動後端
flask --app app run

# 5. 瀏覽器測試
# http://127.0.0.1:5000/api/health
```

**預期回應**：
```json
{"success": true, "data": {"status": "ok"}}
```

## 九、測試環境

跑自動測試**不需要 MySQL**，會自動改用 SQLite 記憶體資料庫：

```powershell
pytest tests/ -v
```

測試時會自動設定：
- `DATABASE_URL=sqlite:///:memory:`
- 獨立的暫存 FAISS 索引（不影響正式資料）

## 十二、常見問題排查

| 問題 | 檢查項目 |
|---|---|
| `pip install` 失敗 | Python 版本、`faiss-cpu` 是否支援目前 Python 版本 |
| 連不上 MySQL | XAMPP MySQL 是否啟動、`DATABASE_URL` 密碼是否正確 |
| `3d_tryon` 不存在 | 先到 phpMyAdmin 手動建庫 |
| 中文亂碼 | 資料庫是否設為 `utf8mb4` |
| 前端 CORS 錯誤 | `CORS_ORIGINS` 是否包含前端實際網址 |
| FAISS 維度錯誤 | `FAISS_VECTOR_DIM` 是否與實際 FashionCLIP 輸出一致（目前 mock 為 512） |
