# GarmentCode 上衣參數表

> 整理日期：2026-10-28
> 來源：`third_party/GarmentCodeRC/assets/design_params/design_used.yaml`（ChatGarment 用的版本，比 GarmentCode 原版多一個 `shirt.openfront`）、
> `third_party/ChatGarment/docs/all_float_paths.json`（AI 用數值輸出的 76 個參數）。只列上衣，下身（裙、褲、腰帶）不列。

**「AI 怎麼給」欄：**
- **選**：AI 第二步輸出的文字 JSON 裡直接選（選項、是非、整數）
- **數值**：AI 另外輸出的 76 個連續數值之一，0～1 再換算到範圍

**「我們」欄：** 目前流程有沒有改它。

## 一、整件衣服（meta、shirt）

| 參數 | 意思 | 範圍（預設） | AI 怎麼給 | 我們 |
|---|---|---|---|---|
| `meta.upper` | 上衣種類：`Shirt` 一般直筒、`FittedShirt` 合身有腰身（下襬固定停在腰）、無 | （無） | 選 | 衣長校正時把 FittedShirt 改成 Shirt |
| `shirt.length` | 衣長（相對腰線的倍數） | 0.5～3.5（1.2） | 數值 | **衣長校正**（hemline.py） |
| `shirt.width` | 寬鬆度 | 1.0～1.3（1.05） | 數值 | 不改。AI 幾乎都給 1.04～1.05 |
| `shirt.flare` | 下襬張開：小於 1 往內收、大於 1 往外張 | 0.7～1.6（1.0） | 數值 | 不改 |
| `shirt.openfront` | 前開襟：前片從上到下分成左右兩片 | 是／否（否） | 選 | 不改。開了目前沒辦法扣起來 |
| `shirt.strapless` | 平口（沒有肩膀） | 是／否（否） | 選 | 不改 |

## 二、領口形狀（collar）

| 參數 | 意思 | 範圍（預設） | AI 怎麼給 | 我們 |
|---|---|---|---|---|
| `collar.f_collar` | 前領口形狀，7 種（見下表） | （CircleNeckHalf） | 選 | **以描述為準修正**（圓、V、方） |
| `collar.b_collar` | 後領口形狀，同 7 種 | （CircleNeckHalf） | 選 | 前領改 V 或方時，後領改回圓 |
| `collar.width` | **領口寬**：0＝脖子寬，1＝接近肩膀，負數比脖子窄 | −0.5～1（0.2） | 數值 | 不改 |
| `collar.fc_depth` | 前領深 | 0.3～2（0.4） | 數值 | **領深校正**（neckline.py） |
| `collar.bc_depth` | 後領深 | 0～2（0） | 數值 | **領深校正** |
| `collar.fc_angle`、`bc_angle` | 前後領口兩側的角度（方領、梯形這類有角的形狀用） | 70～110（95） | 選 | 不改 |
| `collar.f_bezier_x`、`f_bezier_y` | 前領「貝茲曲線」形狀的控制點 | 0.05～0.95 | 數值 | 不改 |
| `collar.b_bezier_x`、`b_bezier_y` | 後領同上 | 0.05～0.95 | 數值 | 不改 |
| `collar.f_flip_curve`、`b_flip_curve` | 把領口曲線反過來（凸變凹） | 是／否（否） | 選 | 不改 |

**7 種領口形狀：**

| 名稱 | 樣子 |
|---|---|
| `CircleNeckHalf` | 圓領 |
| `CurvyNeckHalf` | 彎曲的圓弧領 |
| `CircleArcNeckHalf` | 圓弧領（另一種弧） |
| `Bezier2NeckHalf` | 貝茲曲線領，形狀由 bezier 控制點決定 |
| `VNeckHalf` | V 領 |
| `SquareNeckHalf` | 方領 |
| `TrapezoidNeckHalf` | 梯形領（上寬下窄的方領） |

## 六、左右不對稱（left）

`left.enable_asym` 打開時，左半邊用 `left.*` 這一組（衣服寬、下襬、領口、袖子都可以跟右邊不同），例如單肩上衣。
AI 有輸出這組數值，但目前沒用到，平常左右對稱。

## 目前有機會用上的

| 問題 | 可以用的參數 | 怎麼用 |
|---|---|---|
| **船領**做成普通圓領 | `collar.width` | 描述寫 boat neck 時把領口寬調大（接近 1），領深維持淺 |
| **半高領／高領**分不出來 | `component.depth` | 描述寫 mock neck → 高領、高度 3～4；turtleneck → 7～8（AI 給的高度很亂，i32 高領毛衣只給 2） |
| **長袖沒有縮口** | `cuff.type` | 描述寫 ribbed cuffs → `CuffBand` |
| **大圓領**被改成普通圓領 | `collar.fc_depth`、`collar.width` | 描述寫 scoop 時領深用比較深的比例（但 AI 描述很少寫 scoop） |
| **一字領** | `collar.width`＋`shirt.strapless` | 領口很寬或平口，要試 |
| **心形領** | `Bezier2NeckHalf`＋`f_flip_curve` | 反過來的曲線可能接近心形，要試 |
| **襯衫**做成套頭 | `shirt.openfront` | 開襟做得出來，但扣不起來，要另外處理 |
| **翻領立著** | `component.lapel_standing` | 試過，效果不大，要另找方法 |

**做不出來的：** 扣子、門襟（亨利領、Polo、襯衫的那一小段開口）、口袋、反折的高領。
