# 環境設定｜衣物生成

> 對應第四週週報「所需工具」。換電腦或組員要跑時照著做。

## 需要先裝好
- Git
- Python 3.12（指令 `py -3.12` 能用）
- NVIDIA 顯示卡＋驅動（跑 ChatGarment 用；GarmentCode 只用 CPU）

## 一鍵安裝
在 `newfashion_VT` 根目錄開 PowerShell：
```powershell
powershell -ExecutionPolicy Bypass -File tools\setup\setup.ps1
```
已經裝過的部分會跳過，可以重複執行。它會：
1. 抓 ChatGarment、GarmentCodeRC 原始碼到 `third_party/`（固定在測試過的版本）
2. 建 `third_party/ChatGarment/assets` 連結，指向 GarmentCodeRC 的 assets
3. 建 `.venv`，裝 `tools/chatgarment/requirements.txt`
4. 建 `.venv-chatgarment`，裝 `tools/chatgarment/requirements-ai.txt`（約 3～4 GB）
5. 檢查需要手動放的檔案

## 需要手動放的檔案
| 檔案 | 放在 | 取得方式 |
|---|---|---|
| ChatGarment 權重（14 GB） | `third_party/ChatGarment/checkpoints/try_7b_lr1e_4_v3_garmentcontrol_4h100_v4_final/pytorch_model.bin` | ChatGarment README 的 Pretrained weights 連結（SharePoint，用瀏覽器下載） |
| SMPL-X 權重 | `legacy/geometry_physics/assets/smplx/SMPLX_NEUTRAL.npz`（MALE、FEMALE 同目錄） | https://smpl-x.is.tue.mpg.de/ 註冊下載，授權禁止散布 |

這些都被 `.gitignore` 排除，不會上傳 GitHub。

## 檢查
```powershell
.venv\Scripts\python tools\setup\check_env.py
```
會檢查：檔案是否到位、GarmentCode 能否打版、PyTorch 能否用顯示卡、4-bit 量化、ChatGarment 模型程式、SMPL-X 能否產生人體。全部 ✔ 就完成了。

## 兩個環境
| 環境 | 用途 | 重點版本 |
|---|---|---|
| `.venv` | 打版、縫合、預覽圖、法線貼圖 | numpy 1.26.4、**libigl 2.5.1（不能升級）**、CGAL、trimesh |
| `.venv-chatgarment` | ChatGarment 推論、SMPL-X | PyTorch 2.11（CUDA 12.8）、**transformers 4.37.2（不能升級）**、bitsandbytes、smplx |

兩個環境要分開：套件版本會互相衝突。

## 已知問題
- `setup.ps1` 要存成 **UTF-8 BOM**，不然 Windows PowerShell 5.1 會把中文讀成亂碼而無法執行。
- libigl 2.6 以上會讓 GarmentCodeRC 出錯（`facet_components` 回傳格式改變）。
- RTX 50 系列需要 CUDA 12.8 版的 PyTorch，ChatGarment 原本指定的 torch 2.1.2 不支援。
