# 找圖需求：第三批測試衣服——領口比對（給其他 AI 用）

> 整理日期：2026-10-22
> 用途：專門測「領口」：AI 能不能判斷對領型（圓領、V 領、方領…），以及領深校正後的領口深淺、大小合不合理。
> 數量：**50 件**，每件**正面一張**就夠（背面照有的話順便附上，沒有不用硬找）。

---

## 一、照片條件（每張都要符合）

| 條件 | 說明 |
|---|---|
| 擺法 | **平放**（flat lay）或**掛在隱形人台**（ghost mannequin）上；不要穿在模特兒身上、不要衣架 |
| 數量 | 照片裡**只有一件衣服**，沒有褲子、配件、道具 |
| 構圖 | **整件入鏡**，衣服不要被裁切；衣服佔畫面一半以上 |
| **領口** | **領口要完整、清楚看得到**：不要被摺到、壓到、被標籤或吊牌擋住；拉鍊、扣子拉上扣好 |
| 背景 | **素色**，而且**跟衣服顏色差很多**（白衣服不要白背景、黑衣服不要黑背景） |
| 光線 | 均勻，**沒有強烈陰影** |
| 解析度 | 長邊 600 px 以上 |
| 格式 | jpg 或 png（**不要 webp**） |
| 授權 | 可以免費使用的圖庫（例如 Pexels、Unsplash），或商品頁的官方照；**每張記下來源網址** |

**最理想：** 電商的商品圖（白底或淺灰底），而且**商品頁有寫領型**（例如「圓領」「V 領」「船領」）。
商品頁寫的領型就是這次比對的**正確答案**，請一定要記下來。

## 二、要找的衣服（50 件）

| 組 | 領型 | 件數 | 怎麼挑 | 要測什麼 |
|---|---|---|---|---|
| A | **圓領**（crew neck） | 10 | 短袖 T 恤 4、長袖 T 恤 2、大學 T（sweatshirt）2、合身羅紋 T 2 | 最常見的領型，領深校正的基準（前約 8 cm） |
| B | **大圓領／寬圓領**（scoop neck） | 5 | 領口明顯比一般 T 恤低、寬 | 會不會被誤改成普通圓領（太淺） |
| C | **V 領**（V-neck） | 8 | 淺 V 的 T 恤 3、深 V 的 T 恤 3、V 領毛衣 2 | 淺 V、深 V 能不能分出來（V 領最淺約 13 cm） |
| D | **方領**（square neck） | 4 | 上衣或背心 | 之前常把圓領誤判成方領，這組是真的方領 |
| E | **船領**（boat neck） | 4 | 領口很寬、很淺，橫向一字型 | GarmentCode 有沒有對應的形狀、會判成什麼 |
| F | **高領／半高領**（turtleneck／mock neck） | 5 | 高領毛衣 3、半高領 T 2 | 目前偵測不到高領，這組用來確認 |
| G | **亨利領**（henley） | 3 | 圓領下面有一小段扣子門襟 | 會不會被判成 Polo 或開襟 |
| H | **Polo 翻領** | 3 | 短袖 Polo | 翻領太高的問題 |
| I | **襯衫領** | 3 | 扣子扣好的襯衫 | 襯衫領、門襟 |
| J | **帽 T**（hoodie） | 3 | 套頭帽 T，帽子攤平看得到領口 | 帽子跟領口的接法 |
| K | **其他**：心形領（sweetheart）、一字領（off-shoulder） | 2 | 各 1 | 特殊領型會被判成什麼 |
| | **合計** | **50** | | |

**顏色、件數分配建議：**
- 同一組裡顏色盡量不同，不要全是白色或黑色；**深色衣服的領口邊緣在照片裡要看得清楚**。
- 男款、女款都可以，混著找。

找不到某一組的件數可以用相近的換（例如方領不夠就多找一件 V 領），但請註明換成什麼。
