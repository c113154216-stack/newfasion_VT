# 👕 領口問題與解法｜筆記

> 💡 **一句話**：領口有兩類問題 —— **大小**（太大、太深）和**形狀**（圓領被做成方領、V 領被做成圓領）。大小是 GarmentCode 的設計範圍和我們的縫合造成的；形狀是 AI 第二步的版型參數跟第一步的文字描述矛盾。
> 💻 程式：`tools/chatgarment/neckline.py`（領深校正）、`tools/chatgarment/sew.py`（新縫合）、`tools/chatgarment/to_design.py`（`fix_collar`、`fix_neck_shape`、`fix_sleeveless`）
> 🖼️ 示意圖：`docs/images/領口_寬度與深度.svg`
> 📅 2026-10-14 ～ 10-21

---

## 1️⃣ 現象

| 問題 | 例子 |
|---|---|
| **領口太大** | 圓領 T 恤的領口一圈約 **98～106 cm**，一般 T 恤約 48～54 cm；背面後領挖很深 |
| **形狀錯** | 照片是圓領，網格卻是**方領**（紅 T、灰條紋 T、短版 T、落肩 T） |
| | 照片是 **V 領**，網格卻是圓領（V 領 T） |
| **多了配件** | 圓領 T 恤多了翻領或高領 |
| **少了配件** | Polo 沒有翻領；高領毛衣沒有高領 |

---

## 2️⃣ 領口太大：兩個原因

### 原因 1：GarmentCode 的設計範圍沒有「貼脖圓領」

GarmentCode 的前領深：

```
前領深 ＝ fc_depth × 胸線高度（約 23 cm） ＋ 肩斜補正（約 6.6 cm）
```

設計範圍規定 **fc_depth ≥ 0.3**，所以前領最淺也有 0.3 × 23 ＋ 6.6 ≈ **14 cm**；後領最淺也有 6～8 cm。一般圓領 T 恤前深約 **8 cm**、後深約 **2 cm**。

AI 其實已經判斷出很淺的圓領（0～1 的分數只有 0.004～0.012，幾乎是最淺），換算後還是 0.32 → 前深 14 cm。

> **不是 AI 判斷錯，是 GarmentCode 的範圍裡沒有這麼淺的領口。**

另外試過「調小領口寬度」：沒用。頸側點會沿著斜的肩線往上爬，前中心點不動，領口反而**更深**（71.6 → 74 cm）。見示意圖。

### 原因 2：縫合把肩膀撐開

舊的縫合（`sew.py`）有兩個力：
- 「不能穿進身體」：權重 **10**
- 「邊長維持原長」：權重 **1**

布碰到肩膀的斜面時，可以「滑開包住肩膀」或「原地被撐開」，權重讓「撐開」比較划算。結果**肩膀一圈被撐長**，衣服往下掛，領口被連帶撐大約 **38%**（紅 T：版片 71.6 cm → 縫合後 99.1 cm）。

---

## 3️⃣ 領口太大：解法

### 解法 1：領深校正（`neckline.py`）

1. **最淺的領深用身體頸寬的比例定**：前 0.39、後 0.10 × 頸寬（男性平均頸寬 20.3 cm → 前 8 cm、後 2 cm）
2. **AI 的分數照比例換到新範圍**：0 ＝ 最淺、1 ＝ GarmentCode 原本的最深。AI 判斷「很淺」的會變成真正的圓領，判斷「很深」的照樣很深
3. **不重寫 GarmentCode 的公式**：直接組版片量「參數 → 實際深度」，再反推（不同款式肩斜補正不同，自己寫公式容易錯）

**驗證**：5 種身體 × 14 件款式，70 組全部對到目標，誤差 < 0.2 cm。

**V 領要比較深**（2026-10-21 補）：AI 對圓領、V 領給的深度分數幾乎一樣（都接近 0），共用 0.39 會把普通 V 領改成 8 cm 的淺 V。所以依形狀調整：**V 領的最淺前深 ＝ 0.65 × 頸寬（約 13 cm）**。

### 解法 2：新縫合（`sew.py`）

| 設定 | 作用 |
|---|---|
| **限制拉長**（超過 2% 的邊權重變 100） | 布不能被撐長，只好滑開、搭在肩上 |
| **彎曲剛度 1** | 限制拉長後袖子會擠出細碎皺褶，加上後變成平順的大褶 |

紅 T 實驗：

| 設定 | 領口縫合後 | 拉長超過 10% 的邊 |
|---|---|---|
| 原本 | 99.1 cm | 10.9% |
| 限制拉長 ＋ 彎曲剛度 1 | 75.4 cm | 1.2% |
| ＋ 領深校正 | **51.2 cm** | — |

> 所有設定穿進身體的頂點都是 0%：**不穿模和不拉長可以同時做到**，是原本的權重選錯了。

**副作用**：衣服正確地掛在肩上，整件往上約 **10 cm**，衣服看起來更短 → 由衣長校正處理（見 `筆記_衣長偏短問題與解法.md`）。

### 結果（bf16 新照片）

| 衣服 | 原本流程 | 領深校正 ＋ 新縫合 |
|---|---|---|
| 米色長袖（圓領） | 98 cm | **58 cm**，後領貼回脖子 |
| 白 T | 90 cm | 63 cm |
| 紅 T | 106 cm | 67 cm ⚠️ 還是方領 |
| 灰條紋 T | 106 cm | 69 cm ⚠️ 還是方領 |

紅 T、灰條紋 T 還偏大：領深校正只管**深淺**，不管**形狀**；它們被判成方領，方領的開口本來就比較寬 → 見第 4、5 節。

---

## 4️⃣ 形狀錯：原因

ChatGarment 分**兩次**產生：

| | 問什麼 | 例子（紅 T） |
|---|---|---|
| **第一問** | 用文字描述衣服 | `collar: crew neck`（圓領）✅ |
| **第二問** | 參考描述，產生版型參數 | `f_collar: SquareNeckHalf`（方領）❌、`component: Turtle`（高領）❌ |

**兩次之間沒有強制一致**。模型一個字一個字依機率產生，選領口形狀、配件時，如果兩個選項的機率很接近，就可能選到跟描述矛盾的那個。

**bf16 比 4-bit 更常錯**（圓領衣服的領口形狀）：

| | 4-bit 錯 | bf16 錯 |
|---|---|---|
| 第一批（舊照片＋新照片） | 1 件 | 3～4 件 |
| 第二批（12 件） | 1 件 | 3 件 |
| 多出不該有的配件（第二批，修正前） | 3 件 | 5 件（4 件高領） |

原因不明，樣本也只有 20 件左右，**不能下「4-bit 比較好」的結論**。

> **兩邊的文字描述大多是對的** → 錯的都在第二問 → 可以用描述來修。

---

## 5️⃣ 形狀錯：解法（以描述為準）

在 `to_design.py` 把 AI 的輸出轉成 GarmentCode 款式檔之後，用第一問的描述檢查第二問的參數，矛盾就以描述為準：

| 檢查 | 描述寫的 | 版型改成 |
|---|---|---|
| **領子配件**（`fix_collar`） | crew neck、round、V-neck、collarless | 無配件 |
| | hood（不是 no hood） | 帽子 |
| | turtle、high neck | 高領 |
| | polo collar、point collar、notched collar | 翻領 |
| **領口形狀**（`fix_neck_shape`，10-21 補） | crew neck、round neck、scoop neck | 圓領（原本已經是弧形的不改） |
| | V-neck | V 領 |
| | square neck | 方領 |
| **有沒有袖子**（`fix_sleeveless`，10-21 補） | short sleeves、long sleeves | 有袖 |
| | sleeveless | 無袖 |

看不出來的（例如描述沒寫領子）就**不改**，保留模型的選擇。

### 修正了哪些

| 衣服 | 修正 |
|---|---|
| 紅 T、灰條紋 T、短版 T、落肩 T | 方領 → **圓領**；多出的高領 → 拿掉 |
| V 領 T | 圓領 → **V 領**（前深約 13 cm）；多出的高領 → 拿掉 |
| 長版 T | 無袖 → **有袖** |
| Polo、扣子襯衫 | 補上翻領（襯衫原本被選成高領） |
| 舊照片的條紋上衣、格紋襯衫 | 多出的高領 → 拿掉 |

### 結果（bf16，領深校正＋衣長校正＋新縫合，再加上形狀修正）

對照圖：`output/chatgarment/bf16_3090_領口修正.png`、`bf16_h_領口修正_1／2.png`

| 衣服 | 之前 | 這次 |
|---|---|---|
| 紅 T（g06） | 方領，領口 67 cm | **圓領，58 cm** |
| 灰條紋 T（g07） | 方領，68 cm | **圓領，59 cm** |
| 短版 T（h01） | 方領，65 cm | **圓領，57 cm** |
| 落肩 T（h10） | 方領 | **圓領** |
| V 領 T（h03） | 圓領，58 cm | **V 領，63 cm**（前深約 13 cm） |
| 長版 T（h02） | 無袖 | **有袖** |
| 開襟毛衣（h08） | 弧形領 | V 領 ⚠️ 照片是圓領，描述寫錯 |

下襬維持在衣長校正的位置（不受影響）。

## 6️⃣ 限制

| 問題 | 說明 |
|---|---|
| **描述本身錯就救不了** | 開襟毛衣照片是圓領，描述卻寫 V-neck → 會被改成 V 領；格紋襯衫明明有領子，4-bit 描述卻寫 collarless → 被改成沒有領子 |
| **高領認不出來** | 高領毛衣（捲邊短高領）的描述寫 crew neck，沒有高領 |
| **Polo 領立太高** | GarmentCode 的翻領（SimpleLapel）背面會立起來一圈，不像 Polo 平貼的領子 |
| **前開襟做不好** | 拉鍊帽 T 做成套頭；開襟毛衣做成敞開（照片是扣起來的），GarmentCode 的開襟沒有「扣起來」的狀態 |
| **襯衫看不出門襟** | 扣子襯衫做出來像長袖 T |
| **最淺領深是用平均男性的打版尺寸定的** | 女性、其他身材用頸寬比例換算，還沒有用實際衣服驗證 |
