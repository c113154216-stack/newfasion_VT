# 把商品照片的顏色、花紋貼到版片上

> 整理日期：2026-10-13
> 程式：`tools/texture/bake_front.py`（顏色）、`tools/texture/normal_map.py`（布紋凹凸）
> VS Code：「④ 顏色貼圖」

## 核心想法：貼在版片上，不是貼在縫好的衣服上

GarmentCode 打版時，每片版片都有自己的 2D 座標，也就是 UV。我們把照片的顏色畫進這張 UV 貼圖，之後的流程都不會動到 UV：
- **縫合**只移動 3D 頂點；
- **物理模擬**也只移動頂點。

所以貼一次，縫好、穿上、動起來都會帶著花樣，不用每幀重貼。

```
商品照片 ──┐
           ├─→ 對齊 ─→ 烘焙進 UV 貼圖（texture.png）─→ 縫好的衣服直接套用
衣服網格 ──┘                                         物理模擬時跟著頂點走
```

## 顏色貼圖：四個步驟

| 步驟 | 做什麼 | 用什麼 |
|---|---|---|
| 1. 去背 | 從照片切出衣服範圍 | GrabCut（照片外圈當背景），只留最大一塊並補洞 |
| 2. 平放 | 把 T-pose 衣服所有版片從正面投影成 2D 輪廓，像一張平拍照 | 正面投影 |
| 3. 對齊 | 讓網格輪廓貼合照片輪廓，算出每個頂點對到照片的哪個位置 | 特徵點對應＋薄板樣條（TPS） |
| 4. 烘焙 | 每個三角形依 UV，把照片對應位置的顏色畫進貼圖 | 重心座標內插＋`cv2.remap` |

### 第 3 步的細節（對齊）
1. **找特徵點：** 兩邊輪廓各找 7 個點，分別是領口、左右袖口、下襬兩角、左右腋下（輪廓往內凹最深處）。
2. **取對應點：** 每兩個特徵點之間等距取點，保證袖口對袖口、下襬對下襬。
3. **彎曲網格：** 用薄板樣條把網格平滑地彎過去，`smoothing=5`，避免硬拉出皺摺。

### 為什麼要用 T-pose 的網格
商品照是平放拍的，袖子往兩側攤開。T-pose 手臂水平，正面投影的形狀最接近平拍照。A-pose 袖子往下垂，對不上。

## 布紋凹凸：法線貼圖（另一張圖）

顏色之外，布料表面的織紋、針織的凹凸用法線貼圖表現。Three.js 的材質可以同時吃這兩張圖。

| 做法 | 適合 | 缺點 |
|---|---|---|
| 我們的（亮度當高度＋Sobel） | 素色、織紋明顯的布料 | 印花圖案會被當成凹凸 |
| DeepBump（AI 模型，GPL-3，只當外部工具用） | 不太會被顏色花紋騙 | 會把照片上的皺摺也當成凹凸，邊緣有瑕疵 |

格式用 OpenGL 慣例（綠色 Y 朝上），是 Three.js 預設的。

## 目前成果（2026-10-13）

- **紅領白 T（e01_red_tee）** 正面可以用，3D 檢視頁選「紅領白 T 恤」就能看。
- 只測過這一件。

### 還沒解決的
| 問題 | 原因 | 可能的解法 |
|---|---|---|
| 肩膀附近有紅色色塊、暗點 | 領口和肩線一帶對齊不夠準 | 加肩點特徵點；或領口區只取主色 |
| 照片上的皺摺陰影被貼上去 | 烘焙的是原始照片顏色，含光影 | 去光影（取局部平均亮度再除掉），或只取色不取亮度 |
| 軀幹側邊帶到影子 | 去背邊緣含背景陰影 | 遮罩往內縮幾像素 |
| 背面、袖子背面只有主色 | 商品照只有正面 | 有背面照就用同一套流程貼後片；沒有就鏡射正面花紋或用主色 |
| 只測過一件 | — | 拿 10 張測試照全部跑一次，特別是格紋、條紋 |

## 之後的方向

- **格紋、條紋這種規律花紋：** 從照片裁一塊**重複單元**，在 UV 上**平鋪**，比整張投影更不容易歪，接縫處也對得齊。
- **Logo、印花這種單一圖案：** 繼續用投影，只貼在前片。
- **最後要決定：** 每件商品走哪一種，要自動判斷（AI 款式判斷時順便判斷），還是上架時讓商家選？
