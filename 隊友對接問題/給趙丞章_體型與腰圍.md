## 1. 衣服要照哪個身體縫（請回覆）

三個人要用同一份體型：我照它縫衣服、你照它擺身體、紀泓宇照你送來的身體套衣服。

- **betas**：紀泓宇說你目前打算先固定 **β = 0**，我也先照 β = 0 縫，對嗎？
- **性別模型**：用 `female`、`male` 還是 `neutral`？
- 之後換成使用者的體型時，我需要 `gender_model` ＋ `betas`（32 個）。用什麼方式給我（檔案、後端）可以之後再定

我這邊用 SMPL-X 權重檔自己算身體（betas 全 0 時跟紀泓宇給的 OBJ 每個頂點差 < 1e-6 m），所以只要給參數，不用傳身體網格。

## 2. 腰圍定義：用肚臍高度（三人一起定）

**問題**：規格 T3 的腰圍是「臀與胸之間周長最小的地方」。肚子凸出來的體型沒有腰的凹處，最小值會跑到胸部正下方；臀圍也會量到肚子上。紀泓宇用他的程式重現過：

| 體型（女性） | 腰圍量在（離腳底） | 臀圍量在 |
|---|---|---|
| 一般（betas[1] = 0） | 107 cm | 81 cm |
| 偏胖（betas[1] = +2） | 111 cm，緊貼胸下 | 88 cm，量在肚子上 |

**提議**：改成在**肚臍的高度**量腰圍（水平截面凸包周長），胖瘦都不會跑掉，也比較接近一般人拿皮尺量的方式。紀泓宇和我都同意。

**需要你：**
- 你的尺寸判定也用同一個定義，可以嗎？
- 選一個 SMPL-X 模板的**肚臍頂點**，寫進 `engine/body/landmarks_smplx.json`（現在只有肩峰 4447／7183 和胸骨下緣 5534），選好跟我說編號
