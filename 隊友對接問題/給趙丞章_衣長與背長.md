# 衣長與背長｜林宇鑫 → 趙丞章

> 日期：2026-10-21
> 回覆你問的三件事。

## 1. 尺寸表上的衣長是從哪量到哪

**定案建議：肩頸點 → 下襬**

- 衣服平放，從**肩頸點**（肩線和領口交接的最高點，HPS）**垂直量到下襬**
- 這是一般服飾業尺寸表（身長／着丈）最常用的量法，商家提供的尺寸表大多就是這樣量
- 不是「頸到腰」，也不是後中心沿著背量

我們網頁目前的尺寸表是開發用的假資料（T 恤 S～XL 衣長 66～72 cm），之前沒有寫清楚定義；就以這個為準，我會補進尺寸表的說明。

## 2. 打版用的「頸到腰」會不會改成同一段

**「頸到腰」只是 GarmentCode 內部的換算單位，不是衣長的定義，不用改。**

- GarmentCode 的版片長度 ＝ 衣長參數 × 頸到腰（例如 1.5 × 38.3 cm），所以紀泓宇的交接說明會這樣寫
- 但我們現在是**先決定下襬落在身體哪裡，再反推衣長參數**（見第 3 點），頸到腰只是中間的換算
- 衣服生成之後，我可以直接在版片上量**肩頸點 → 下襬**，跟尺寸表同一段；要的話每件衣服輸出時附上這個數字

所以要對齊的是「量法」，不是打版的換算方式：**尺寸表、生成的衣服、身體上的背長，三個都用「肩頸點 → 下襬落點」這一段。**

## 3. 下襬在身體上是固定落點，還是每件不一樣

**依款式不同，不是一個固定點。**

我們用身體上的位置定下襬（換身體會自動跟著變）：

| 款式 | 一般長度的下襬規則 |
|---|---|
| T 恤、Polo | 臀圍線往下，「臀圍線到胯下」距離的 0.5 倍 |
| 帽 T、毛衣、長袖 | 臀圍線往下 0.3 倍 |
| 襯衫、背心、開襟外套 | 還沒訂 |

但最後的下襬是「**這個規則位置**」和「**AI 從照片判斷的位置**」各取一半，所以同一類衣服也會差 1～2 cm。以男性平均身材為例，縫好之後 T 恤約在離地 93～94 cm、帽 T／毛衣約 94～96 cm（臀部上方、蓋過褲頭）。

**建議背長的終點：** 跟款式走，用「這一類衣服的規則下襬位置」當終點，也就是

```
背長（身體） ＝ 肩頸點 → 該款式的下襬落點
衣長判定   ＝ 尺寸表衣長 − 背長
```

這樣比較的才是同一段。如果一個人只量一個背長、所有款式共用，建議用 T 恤的落點。
