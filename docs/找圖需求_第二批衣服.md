# 找圖需求：第二批測試衣服（給其他 AI 用）

> 整理日期：2026-10-20
> 用途：測試「照片 → AI 判斷款式 → 生成 3D 衣服網格 → 貼上顏色」這套流程。
> 這批要找的是**容易出問題的款式**，用來檢查程式的弱點；每件都要**正面＋背面**兩張（背面之後拿來貼顏色）。

---

## 一、照片條件（每張都要符合）

| 條件 | 說明 |
|---|---|
| 擺法 | **平放**（flat lay）或**掛在隱形人台**（ghost mannequin）上；不要穿在模特兒身上、不要衣架 |
| 數量 | 照片裡**只有一件衣服**，沒有褲子、配件、道具（相機、太陽眼鏡、花） |
| 構圖 | **整件入鏡**，衣服不要被裁切；衣服佔畫面一半以上 |
| 背景 | **素色**，而且**跟衣服顏色差很多**（白衣服不要白背景、黑衣服不要黑背景） |
| 光線 | 均勻，**沒有強烈陰影**（不要陽光斜射、不要重的落影） |
| 正反面 | **同一件衣服**的正面和背面各一張，擺法、角度盡量一致 |
| 解析度 | 長邊 600 px 以上 |
| 格式 | jpg 或 png（**不要 webp**，我們的程式讀不了） |
| 授權 | 可以免費使用的圖庫（例如 Pexels、Unsplash），或商品頁的官方照；**每張記下來源網址** |

**最理想：** 電商的商品圖（同一件衣服的正面、背面兩張，白底或淺灰底），通常最符合條件。

---

## 二、要找的衣服（12 件 × 正反 2 張 ＝ 24 張）

每一件都是為了測某個可能出問題的地方：

| # | 款式 | 為什麼要測 | 注意 |
|---|---|---|---|
| 1 | **短版 T 恤**（cropped tee） | 衣長規則：短版要停在腰附近 | 下襬明顯在腰以上的那種 |
| 2 | **長版 T 恤**（longline / oversized long tee） | 衣長規則：長版要比一般 T 恤長 | 下襬蓋過臀部 |
| 3 | **V 領 T 恤** | 領深校正可能把 V 領改得太淺 | 普通深度的 V 領 |
| 4 | **Polo 衫**（短袖、有翻領、有扣子門襟） | 翻領要保留、領型判斷 | 素色比較好 |
| 5 | **長袖扣子襯衫**（button-down shirt） | 襯衫領、前開扣、合身款判斷 | 扣好扣子平放 |
| 6 | **背心**（tank top，無袖） | 無袖、領口很深 | 一般運動背心或內搭背心 |
| 7 | **拉鍊帽 T**（zip-up hoodie） | 前開襟＋帽子 | 拉鍊拉上 |
| 8 | **開襟毛衣**（cardigan，有扣子） | 前開襟、V 領、毛衣 | 扣子扣上 |
| 9 | **高領毛衣**（turtleneck） | 高領配件 | 領子立起來看得出高領 |
| 10 | **寬鬆落肩 T 恤**（oversized / drop shoulder） | 寬鬆度、肩線位置 | 肩線明顯掉到手臂上 |
| 11 | **橫條紋長袖 T 恤**（striped long sleeve） | 顏色貼圖：條紋在縫線兩側能不能對齊 | 條紋清楚、間距明顯 |
| 12 | **背面有印花的 T 恤**（back print tee） | 顏色貼圖：背面要貼到背面的圖案 | 正面素色或小 logo、背面大圖案 |

找不到某一件可以跳過，或換成相近的款式，但請註明換成什麼。

---

## 三、交回來的方式

1. 全部放進：`C:\Users\User\Desktop\newcloth2\`
2. 檔名照這個格式（**不用管編號**，我們這邊會重新命名）：

   ```
   <顏色>_<款式>_front.jpg
   <顏色>_<款式>_back.jpg
   ```

   例如：`white_cropped_tee_front.jpg`、`white_cropped_tee_back.jpg`
3. 同一個資料夾放一份 `sources.md`，每件寫：
   - 對應上面表格的第幾件
   - 正面、背面的來源網址
   - 授權（例如 Pexels License）

---

## 四、我們這邊收到之後

- 重新命名成 `h01_` ～ `h12_` 開頭（第一批是 `e`、`x`，第二批是 `g`，不重複），例如 `h01_white_cropped_tee.png`
- 正面照拿去 3090 跑 AI 判斷款式；背面照另外放，之後貼顏色用
- 轉成 png（webp 之類的格式也會自動轉）

## 附：3090 補跑（g01、g02）

上次 3090 漏跑的兩件（`.webp` 被跳過），已經轉好 png，放在：

```
newfashion_VT/output/chatgarment_ai/inputs_3090_extra/
├── g01_navy_fish_print_tee.png
└── g02_black_tee.png
```

複製到 3090 之後，在 `newfashion_VT` 資料夾執行：

```bash
python tools/chatgarment/infer.py --mode bf16 --images output/chatgarment_ai/inputs_3090_extra --out output/chatgarment_ai/bf16_extra
```

（`python` 換成那台 ChatGarment 環境的 python。）把 `output/chatgarment_ai/bf16_extra/` 帶回來。名稱已經是 `g01`、`g02`，跟 4-bit 的結果對得上，不用改名。

第二批的 12 件找到之後，也可以一起帶去 3090 跑，每張約 15 秒。
