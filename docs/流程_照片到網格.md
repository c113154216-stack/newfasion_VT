# 🧵 流程：商品照片 → 3D 衣服網格（交付給 engine）

> 📅 整理日期：2026-11-10（目前版本，68 件已照這個流程匯出到 VTO_PROJ `garment/meshes/neutral/`）
> 👤 林宇鑫

```
① 整理照片 → ② ChatGarment 推論 → ③ 轉成版型參數＋描述修正 → ④ 校正（領深、衣長、袖長）
→ ⑤ GarmentCode 打版、擺到身體旁 → ⑥ 縫合＋尖角攤平 → ⑦ 匯出、標固定點 → ⑧ 交付檢查、推到 VTO_PROJ
```

| 步驟 | 做什麼 | 程式 | 環境 | 輸出 |
|---|---|---|---|---|
| ① 整理照片 | 改名（編號_顏色_款式）、webp 轉 png、透明背景填反差色；背面照另放 `_back` | `import_photos.py` | `.venv` | `output/chatgarment_ai/inputs_*` |
| ② AI 推論 | ChatGarment（LLaVA-7B＋LoRA）：照片 → 文字描述 JSON ＋ 76 個 0～1 數值。顯示卡 ≥ 20 GB 用 bf16，否則 4-bit | `infer.py` | `.venv-chatgarment` | `output.json`、`float_preds.npy` |
| ③ 轉版型參數 | 76 個數值還原成 GarmentCode `design.yaml`（用作者的 `recursive_change_params_1float`）；再用文字描述修正「描述對、版型錯」：領子配件、領口形狀、有無袖子、袖口縮口 | `to_design.py` | `.venv` | `results/chatgarment_ai/<批次>/<衣服>/design_upper.yaml` |
| ④ 校正 | **領深**：最淺改成頸寬比例（前約 8、後約 2 cm）<br>**衣長**：目標下襬＝(AI 下襬＋款式規則下襬)÷2<br>**袖長**：長袖調到袖口在手腕；短袖、無袖照 AI | `neckline.py`、`hemline.py`、`sleevelen.py`（都在 `export_neutral.py` 裡呼叫） | `.venv` | 改過的 design |
| ⑤ 打版 | GarmentCode 依 design ＋ 身體尺寸檔畫 2D 版片，擺到身體周圍成 box mesh（頂點間距 2 cm） | `design_to_mesh.py`（GarmentCodeRC） | `.venv` | box mesh、原始邊長 |
| ⑥ 縫合 | 純幾何求解（不是物理）：每條邊回到版片原長、拉長超過 2% 變硬、彎曲剛度 1、壓短限制 2%、頂點不進身體；縫完把縫線交會處翻摺的尖角面攤平 | `sew.py`（含 `unfold`） | `.venv` | 縫好的衣服 |
| ⑦ 匯出 | 公尺、移回 SMPL-X 原始座標（和 engine 身體同座標）；固定點 `neck_shoulder_band`（蒙皮權重最大的是頸或鎖骨、離身體 1 cm 內） | `export_neutral.py` | `.venv` | `<衣服>.obj`、`_pins.json`、`fix.json`、`design_used.yaml` |
| ⑧ 檢查、交付 | 尖角、自我穿插、穿進身體、袖管鬆度、頂點數 ≤ 4,000；obj 拿掉 mtllib／usemtl 後放進 VTO_PROJ | `experiments/delivery_check.py`、`neutral_preview.py` | `.venv` | `_logs/delivery_check.json`、`preview.png` |

### 📐 身體（全部步驟共用）

- 縫衣服用：**SMPL-X 中性、θ＝0（T-pose）、β 全 0**，身高 172.1 cm。
- 打版尺寸檔：GarmentCode 的 `mean_all.yaml`（GarmentCodeData 平均身材，身高 172.0 cm；只把手臂角度改成 0）。不用舊的 `f_smpl_template`（人工量法，手臂長 80 cm，袖子會長 14～27 cm）。
- 換使用者體型：engine（紀泓宇）那邊處理，同一件衣服可容許身高 ±10 cm、肩寬 ±3 cm。

### 🔁 第 ④～⑥ 步實際怎麼串（每件衣服）

1. 領深校正 → 用 AI 的衣長、袖長**先縫一次**，量下襬高度和袖口離手腕。
2. 算新的衣長參數、袖長參數 → **再縫一次**。
3. 下襬或袖口還差超過 1 cm → 用兩次實測的斜率修正 → **第三次縫合**。
4. 尖角攤平 → 匯出。

一件約十幾秒到一分鐘；68 件分 5 個程序平行跑（`output/physics_export/neutral/_logs/run_all.sh`）。
