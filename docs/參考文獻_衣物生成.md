# 📚 參考文獻｜衣物生成（ChatGarment ＋ GarmentCode 路線）

> 💡 依「在流程中的角色」分組。格式比照計畫書（IEEE）。
> ⭐ = 直接使用它的程式或模型；📖 = 方法參考；🔍 = 調查過但沒有採用

## 一、核心：照片 → 款式參數 → 衣服網格

| | 論文 | 在我們流程中的角色 |
|---|---|---|
| ⭐ | **ChatGarment**（CVPR 2025） | 看商品照，輸出 GarmentCode 的款式參數（`design.yaml`）。用作者訓練好的權重做推論 |
| ⭐ | **GarmentCode**（SIGGRAPH Asia 2023） | 款式參數＋身體尺寸 → 2D 版片 → 3D box mesh。實際用的是 ChatGarment 作者修改過的 GarmentCodeRC |
| ⭐ | **GarmentCodeData**（ECCV 2024） | GarmentCode 的資料集版本；ChatGarment 的訓練資料由它生成。我們沒有下載 |

- [1] S. Bian, C. Xu, Y. Xiu, A. Grigorev, Z. Liu, C. Lu, M. J. Black, and Y. Feng, "ChatGarment: Garment estimation, generation and editing via large language models," in *Proc. IEEE/CVF Conf. Comput. Vis. Pattern Recognit. (CVPR)*, 2025. arXiv:2412.17811. 程式：https://github.com/biansy000/ChatGarment
- [2] M. Korosteleva and O. Sorkine-Hornung, "GarmentCode: Programming parametric sewing patterns," *ACM Trans. Graph.*, vol. 42, no. 6, 2023, doi: 10.1145/3618351. 程式：https://github.com/maria-korosteleva/GarmentCode
- [3] M. Korosteleva, T. L. Kesdogan, F. Kemper, S. Wenninger, J. Koller, Y. Zhang, M. Botsch, and O. Sorkine-Hornung, "GarmentCodeData: A dataset of 3D made-to-measure garments with sewing patterns," in *Proc. Eur. Conf. Comput. Vis. (ECCV)*, 2024. arXiv:2405.17609.

| | 論文 | 角色 |

## 四、縫合（`sew.py`）的方法參考

| | 論文 | 角色 |
|---|---|---|
| 📖 | **Projective Dynamics** | `sew.py` 的「局部－全域交替求解」：局部算每條邊的目標、全域解一次線性方程組。我們只取求解方式，沒有重力和動態 |

- [12] S. Bouaziz, S. Martin, T. Liu, L. Kavan, and M. Pauly, "Projective dynamics: Fusing constraint projections for fast simulation," *ACM Trans. Graph.*, vol. 33, no. 4, 2014.

## 五、調查過、沒有採用的

| | 論文 | 沒採用的原因 |
|---|---|---|
| 🔍 | **Multi-Garment Net（MGN）**，ICCV 2019 | 舊專案的 5 個公版來源；新路線不用公版，而且限非商用 |
| 🔍 | **AIpparel**，CVPR 2025 | 同樣是照片 → 版型，ChatGarment 已經足夠，而且直接接 GarmentCode |
| 🔍 | **GarmentX**，2025 | 同上 |
| 🔍 | **GarmageNet**，SIGGRAPH Asia 2025 | AI 直接生成版片幾何（B 路線）；如果之後要「AI 直接生成網格」再評估 |
| 🔍 | **DressWild**，2026 | 任意姿勢照片 → 版型；程式碼狀態未確認 |
| 🔍 | **Dress-1-to-3**，2025 | 加可微分模擬細修，太重，偏離線處理 |
| 🔍 | **GarmentCrafter**，3DV 2026 | 直接重建網格，跟身材、版型沒有關聯 |
| 🔍 | **Garment3DGen**，2024 | 公版變形路線，已放棄 |
| 🔍 | TripoSG、Hunyuan3D、TRELLIS | 通用照片轉 3D，輸出實心物體、大小無法控制 |

- [13] B. L. Bhatnagar, G. Tiwari, C. Theobalt, and G. Pons-Moll, "Multi-Garment Net: Learning to dress 3D people from images," in *Proc. IEEE/CVF Int. Conf. Comput. Vis. (ICCV)*, 2019. arXiv:1908.06903.
- [14] K. Nakayama *et al.*, "AIpparel: A multimodal foundation model for digital garments," in *Proc. IEEE/CVF Conf. Comput. Vis. Pattern Recognit. (CVPR)*, 2025. arXiv:2412.03937.
